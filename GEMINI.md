## Development

When starting the dev server, use background mode:

```
astro dev --background
```

Manage the background server with `astro dev stop`, `astro dev status`, and `astro dev logs`.

Project Specification & Execution Roadmap (AGENTS.MD)1. System Vision & OverviewThe goal is to build a zero-cost, hyper-personalized, web-based command dashboard powered entirely by built-in, modular code functions—eliminating all third-party AI APIs (like Gemini or OpenAI) and external service APIs.The system relies on local pattern matching and custom intent handlers coded directly into the application. You can freely edit, modify, or add new functions (e.g., custom greetings, launching local applications, managing preferences). Memory is saved directly to Google Sheets via a lightweight web script, browsing keywords are captured locally via a Chrome extension, and local system commands are executed through a background helper script.2. Core Architecture & Feature MatrixA. Central Interface & Voice-Text HubFull-Screen Responsive Layout: A sleek, dark-themed canvas designed for desktop monitors without unnecessary scrollbars or clutter.Center Stage Node: A prominent, glowing central floating widget containing:Interactive Voice Button: Click-to-speak or wake-word listening using native browser Web Speech APIs.Text Input Field: An integrated chat bar beneath the central widget for typed commands.Live Speech Visualizer: Audio wave animations that respond while the user speaks or when the assistant speaks back.Status Indicator: Visual cues displaying state changes (Listening, Matching Intent, Updating Memory, Executing Function).Local Intent Engine (No AI API): Direct pattern matching (e.g., regex/keyword rules) written in your code that maps user input directly to custom JS/Python functions (e.g., greetUser(), openApplication(), saveFact()).B. Surrounding Dashboard Grid & Dynamic FeedsPersonalized Content Feeds: Dynamic cards positioned around the central hub that auto-refresh based on local keyword logs:YouTube Media Tile: Standard embedded YouTube iframe cards dynamically generated from search query strings (no YouTube Data API key required).Topic & Product Discovery Tile: Direct URL embeds or RSS card links built from your recent search keywords.Memory Knowledge Graph Tile: A live visual feed displaying facts stored in your database (e.g., name, current learning goals, system shortcuts).Quick Actions Panel: One-click buttons linked directly to built-in code triggers (e.g., draft email, open VS Code, clear temporary logs).C. Self-Managing Google Sheets Memory EngineBi-Directional Synchronized Memory: Google Sheets acts as the central persistent database via Google Apps Script (no external database subscription or API key required).Code-Driven Structuring & Storage:Uses deterministic code parsing (e.g., matching phrases like "My [key] is [value]" or "Remember that [key] = [value]") to save data.Directly handles creating, reading, updating, overwriting, and deleting spreadsheet rows through simple HTTP requests to your Apps Script URL.Organizes records into clean categories (Identity_Facts, Interests_Log, Task_Routines).D. Activity Tracking & Data Collection EngineChrome Extension Monitor: A lightweight background browser extension that captures active tab titles, search terms, and video titles.Direct Keyword Sync: Sends extracted keywords directly to your Google Sheets web app endpoint without external processing.E. Local System Automation HelperDesktop Command Bridge: A local background script (Node.js or Python) running on your computer to bridge web dashboard actions to your operating system.Direct System Execution: Houses your custom code functions for system actions (e.g., executing OS commands to launch VS Code, Spotify, Terminal, or triggering system-level mailto: protocols).3.
